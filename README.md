# 🔮 AI 타로 상담 (ai-tarot)

실제 타로 상담처럼 **질문을 먼저 하고 → 카드를 뽑으면 → AI가 카드를 보며 그 질문에 답해 주는** 웹앱입니다.
78장 전체 덱과 3가지 스프레드를 지원하고, 해석은 Google Gemini API가 맡습니다.

- 배포 주소: https://ai-tarot-xi.vercel.app
- 구성: 정적 페이지(`index.html`) + Vercel 서버리스 함수(`api/tarot.js`)

---

## 주요 기능

- **질문 기반 리딩**: 질문을 입력하면 AI가 질문에 대한 핵심 답을 먼저 말하고, 카드별 해석과 실천 조언을 이어서 들려줍니다.
- **78장 전체 덱**: 메이저 아르카나 22장 + 마이너 아르카나 56장(완드·컵·소드·펜타클 각 에이스~킹)
- **스프레드 3종**
  - 원카드(1장): 오늘의 답
  - 쓰리카드(3장): 현재 상황 / 걸림돌·핵심 / 조언·결과
  - 켈틱 크로스(10장): 현재 상황, 도전 과제, 근본 원인, 가까운 과거, 의식·목표, 가까운 미래, 나의 태도, 주변 환경, 희망과 두려움, 최종 결과
- **역방향 카드**: 체크박스로 포함 여부 선택
- **카드 일러스트**: 이미지 파일 없이 SVG 코드로 그린 78장
  - 메이저: 로마 숫자 + 카드별 상징 그림
  - 마이너: 수트별 색상 + 숫자만큼 배치한 문양
  - 코트 카드(페이지·나이트·퀸·킹): 서로 다른 왕관/투구 모양
- **카드 뒤집기 연출**: 카드가 차례로 뒤집힌 뒤 리딩이 표시됩니다.
- 모바일 화면에 맞춘 반응형 레이아웃

---

## 폴더 구조

```
ai-tarot/
├─ index.html      # 화면 + 덱 데이터 + 카드 일러스트(SVG) + 카드 뽑기 로직
├─ api/
│  └─ tarot.js     # Vercel 서버리스 함수: Gemini API 호출 (API 키는 서버에서만 사용)
└─ README.md
```

> 이미지 파일은 없습니다. 모든 카드 그림이 `index.html` 안의 코드로 만들어집니다.

---

## 동작 방식

1. 사용자가 질문과 스프레드를 고르고 **카드 뽑기**를 누릅니다.
2. 브라우저에서 78장을 섞어(Fisher–Yates) 필요한 장수만큼 뽑고, 역방향 여부를 정합니다.
3. 브라우저가 `POST /api/tarot`로 **질문 + 스프레드 이름 + 카드 정보(위치, 이름, 정/역방향)** 를 보냅니다.
4. 서버리스 함수가 환경변수의 API 키로 Gemini를 호출합니다.
5. Gemini가 타로 리더 역할의 시스템 지시문에 따라 답변을 만들고, 화면에 표시합니다.

API 키는 브라우저로 내려가지 않고 `process.env.GEMINI_API_KEY`로만 읽습니다. **키를 코드에 직접 적지 마세요.**

---

## 환경변수 (Vercel)

| 이름 | 필수 | 설명 |
|---|---|---|
| `GEMINI_API_KEY` | 필수 | Google AI Studio에서 발급한 Gemini API 키 |
| `GEMINI_MODEL` | 선택 | 사용할 모델 이름. 없으면 코드의 기본값(`gemini-3.8-flash`) 사용 |

환경변수는 **저장한 뒤 재배포(Redeploy)해야 적용**됩니다.

## 배포 방법 (깃 명령어 없이 웹에서만)

### 1. GitHub 저장소 만들기
1. GitHub → 우측 상단 `+` → **New repository**
2. 이름 `ai-tarot`, Description 입력, Public/Private 선택, **Create repository**

### 2. 파일 올리기
1. 저장소에서 **Add file → Upload files**
2. `index.html`과 `api` 폴더(안에 `tarot.js`)를 끌어다 놓고 **Commit changes**
3. 저장소 맨 위에 `index.html`과 `api` 폴더가 보이고, `api` 안에 `tarot.js`가 있는지 확인

> 파일이 폴더 없이 맨 위에 올라갔다면: 해당 파일 → 연필(Edit) → 파일 이름 앞에 `api/`를 붙이고 Commit 하면 폴더 안으로 이동됩니다.

### 3. Gemini API 키 발급
1. https://aistudio.google.com/apikey 접속 → **API 키 만들기**
2. 만들어진 키의 **결제 등급** 칸이 `무료 등급`인지 확인 (아래 트러블슈팅 참고)

### 4. Vercel 배포
1. https://vercel.com 에 GitHub 계정으로 로그인
2. **Create New → Project** → `ai-tarot` 저장소 Import (Framework Preset은 `Other`, 나머지는 기본값)
3. **Environment Variables**에 `GEMINI_API_KEY` 추가 (값에 발급받은 키 입력)
4. **Deploy**

## 만든 과정

1. **기획**: 실제 타로 상담처럼 "질문 → 카드 → 질문에 맞춘 답변" 흐름으로 설계. 해석은 Gemini API 사용.
2. **구조 결정**: API 키 노출을 막기 위해 브라우저에서 직접 호출하지 않고 Vercel 서버리스 함수(`api/tarot.js`)를 거치게 구성.
3. **1차 버전**: 메이저 아르카나 22장, 쓰리카드 스프레드.
4. **78장 전체 덱**: 마이너 아르카나 56장은 수트(4) × 랭크(14) 조합으로 코드에서 생성. 스프레드를 원카드/쓰리카드/켈틱 크로스 3종으로 확장하고, 서버가 1~10장을 받도록 수정.
5. **카드 일러스트**: 이미지 대신 SVG로 78장을 그림. 메이저는 카드별 상징 그림 22개, 마이너는 숫자별 문양 배치표와 코트 카드용 왕관 4종으로 구성.
6. **배포**: GitHub 웹에서 파일 업로드 → Vercel Import → 환경변수 등록 → 배포.
7. **오류 대응**: 아래 트러블슈팅 참고.

## 트러블슈팅 (실제로 겪은 문제)

### 1. `models/gemini-2.5-flash is no longer available to new users`
- **원인**: 코드에 넣어둔 모델이 신규 사용자에게 더 이상 제공되지 않음.
- **해결**: 에러 문구가 안내한 새 모델로 변경하고, 새 모델과 맞지 않을 수 있는 `thinkingConfig` 설정을 제거. 이후에는 모델 이름을 `GEMINI_MODEL` 환경변수로 바꿔 코드 수정 없이 교체할 수 있게 함.

### 2. `The Gemini API free tier is not available for this project`
- **원인**: 사용한 구글 프로젝트의 무료 등급이 막혀 있음. AI Studio 비율 제한 화면에는 "무료 등급"이라고 보여도, **API 키 목록의 `결제 등급` 칸**에는 `무료 등급 사용 불가`로 표시되어 있었음. 새 프로젝트를 만들어 가져와도 같은 표시가 나왔음.
- **해결**: 프로젝트 가져오기 목록에서 `무료 등급`으로 표시된 다른 프로젝트로 새 키를 만들고, 그 키의 결제 등급이 `무료 등급`인 것을 확인한 뒤 Vercel의 `GEMINI_API_KEY`를 교체 → 재배포.
- **팁**: 키를 만든 직후 **API 키 목록의 `결제 등급` 칸**을 꼭 확인하세요. `무료 등급 사용 불가`가 보이면 그 키로는 무료 사용이 안 됩니다.

### 3. 환경변수를 바꿨는데 반영이 안 됨
- **원인**: Vercel은 환경변수를 저장해도 **새로 배포해야** 적용됨.
- **해결**: Deployments → 맨 위 배포의 `⋯` → **Redeploy**, 완료(Ready) 후 `Ctrl+Shift+R`로 새로고침.

### 4. `tarot.js`가 `api` 폴더 밖에 올라감
- **원인**: GitHub의 Upload files로 올리면 폴더 구조가 유지되지 않는 경우가 있음.
- **해결**: 파일 편집 화면에서 이름 앞에 `api/`를 붙여 이동.

## 알아둘 점

- **무료 한도**: 무료 등급에는 분당/하루 요청 한도가 있습니다. 플래시 라이트 계열이 일반 플래시 계열보다 하루 한도가 넉넉합니다(2026-10-30 AI Studio 비율 제한 화면 기준). 켈틱 크로스를 연달아 하면 한도에 걸릴 수 있어요.
- **개인정보**: 무료 등급에서는 입력 내용이 구글의 서비스 개선에 쓰일 수 있다고 안내됩니다. 민감한 개인 정보는 입력하지 마세요.
- **Vercel Hobby 플랜**은 개인·비상업용입니다. 광고를 붙이거나 유료 서비스로 운영하려면 약관을 확인하세요.
- **API 키**는 절대 코드/README/이슈에 적지 마세요. 노출되었다면 AI Studio에서 키를 삭제하고 새로 발급받으세요.
- 이 앱의 리딩은 **오락·자기 성찰용**이며, 건강·법률·투자 등 중요한 결정의 근거가 될 수 없습니다.

## 로컬에서 확인하기

- `index.html`을 브라우저로 열면 카드 뽑기와 일러스트까지는 확인할 수 있습니다. (AI 리딩은 `/api/tarot`가 필요해서 동작하지 않습니다.)
- 리딩까지 로컬에서 테스트하려면 Vercel CLI의 `vercel dev`와 `GEMINI_API_KEY` 환경변수가 필요합니다.
